เขตเป้าหมายบนกราฟ

แต่ละกระบวนการคือการเปลี่ยนอากาศจากสถานะต้นทางไปปลายทาง เช่น คอยล์เย็น ฮีตเตอร์ หรือเครื่องทำความชื้น ใส่ได้หลายกระบวนการต่อเนื่องกัน

เครื่องมือเพิ่มเติม

1 · ผสมอากาศ (Mixing)

คิดสมดุลมวลอากาศแห้ง ถ่วงน้ำหนักด้วยมวล (อัตราไหลที่แต่ละสถานะ ÷ v) แล้วหาอุณหภูมิจากเอนทัลปีและความชื้นจำเพาะ

2 · สถานะหลังคอยล์เย็น (ADP / BF)

BF

จุดหลังคอยล์อยู่บนเส้นตรงระหว่างอากาศเข้ากับ ADP: Tออก = ADP + BF·(Tเข้า − ADP) และ Wออก คิดแบบเดียวกัน (Contact factor = 1 − BF)

3 · โหลดห้อง → ปริมาณลมจ่าย

ṁ = Qs ÷ [(1.006 + 1.86·W)·(Tห้อง − Tจ่าย)] และ Wจ่าย = Wห้อง − Ql ÷ (ṁ·2501) ค่า Q เป็นความร้อนที่ห้องได้รับ

แผนภูมิ Psychrometric ที่ระดับน้ำทะเล

ขอบเขตและสมมติฐาน

แอปคำนวณตามสมการใน ASHRAE Handbook—Fundamentals บทที่ 1 (Psychrometrics) ภายในเป็นหน่วย SI เสมอ แล้วแปลงเป็น IP ตอนป้อนและแสดงผล จึงสลับหน่วยไปมาได้โดยค่าไม่เพี้ยน

  • ช่วงที่คำนวณได้ Tdb −40 ถึง 80 °C ใช้สมการ Pws ช่วงน้ำแข็งและช่วงน้ำตามอุณหภูมิ
  • กราฟ SI แสดง 0–50 °C และ W ถึง 30 g/kg กราฟ IP แสดง 32–120 °F และ W ถึง 0.028 lb/lb (196 gr/lb) ตามช่วงของ ASHRAE Psychrometric Chart No.1
  • ถือว่าอากาศและไอน้ำเป็นก๊าซอุดมคติ ไม่ใส่ enhancement factor ของไอน้ำ ทำให้ W อิ่มตัวต่ำกว่าตารางของ ASHRAE เล็กน้อย (ประมาณ 0.4 % ที่ 20 °C)
  • นิยาม RH ที่ใช้ φ = Pw / Pws ที่ Tdb และความดันเดียวกัน
  • ความดันบรรยากาศคำนวณจากระดับความสูง ใช้ร่วมกันทุกสถานะและทุกเส้นบนกราฟ
สมการสถานะอากาศ

ความดันไอน้ำอิ่มตัว Pws (Hyland–Wexler) T = t + 273.15 K, Pws เป็น Pa

t ≥ 0 °C ln Pws = C8/T + C9 + C10·T + C11·T² + C12·T³ + C13·ln T C8 = −5.8002206e3 C9 = 1.3914993 C10 = −4.8640239e−2 C11 = 4.1764768e−5 C12 = −1.4452093e−8 C13 = 6.5459673 t < 0 °C ln Pws = C1/T + C2 + C3·T + C4·T² + C5·T³ + C6·T⁴ + C7·ln T C1 = −5.6745359e3 C2 = 6.3925247 C3 = −9.677843e−3 C4 = 6.2215701e−7 C5 = 2.0747825e−9 C6 = −9.484024e−13 C7 = 4.1635019

สมบัติอื่น (p คือความดันรวม kPa)

W = 0.621945 · Pw / (p − Pw) [kg/kg] Pw = RH · Pws h = 1.006·t + W·(2501 + 1.86·t) [kJ/kg dry air] v = 0.287042·(t + 273.15)·(1 + 1.607858·W) / p [m³/kg dry air] ρ = (1 + W) / v [kg/m³]

กรณีป้อน h คำนวณ W = (h − 1.006·t) / (2501 + 1.86·t) ส่วนกรณีป้อน W ใช้ Pw = p·W / (0.621945 + W)

การหา Twb และ Tdp

Twb (t*) หาจากสมการสมดุลพลังงานของกระเปาะเปียก แล้วแก้ t* ด้วยวิธี bisection (60 รอบ) จนได้ W ตรงกับที่ต้องการ

t* ≥ 0: W = [(2501 − 2.326·t*)·W*s − 1.006·(t − t*)] / (2501 + 1.86·t − 4.186·t*) t* < 0: W = [(2830 − 0.24·t*)·W*s − 1.006·(t − t*)] / (2830 + 1.86·t − 2.1·t*) W*s = W อิ่มตัวที่ t*

Tdp คืออุณหภูมิที่ Pws(Tdp) = Pw แก้ด้วย bisection เช่นกัน ถ้า Pw ต่ำมาก (W ≈ 0) จะแสดง “—”

โหลดของกระบวนการ A → B
ṁ = V / (3600 · v_A) [kg/s dry air] Q = ṁ · (h_B − h_A) [kW] C = จุด (t_B, W_A) Qs = ṁ · (h_C − h_A) Sensible Ql = ṁ · (h_B − h_C) Latent SHR = |Qs| / |Q| น้ำควบแน่น = ṁ · (W_A − W_B) · 3600 [kg/h] 1 TR = 3.517 kW = 12,000 Btu/h
  • V คืออัตราไหลของอากาศที่สถานะต้นทาง (m³/h หรือ CFM)
  • เครื่องหมายลบหมายถึงดึงความร้อนออก
  • เส้นกระบวนการบนกราฟเป็นเส้นตรงระหว่างสองจุด (เส้นทึบสีน้ำเงิน = ทำความเย็น, สีแดง = ให้ความร้อน, เส้นประ = เส้นผสมอากาศจากเครื่องมือผสม ซึ่งไม่นับเป็นกระบวนการ) ซึ่งเป็นการประมาณ เส้นจริงของคอยล์เย็นเป็นเส้นโค้ง แต่โหลดที่คำนวณขึ้นกับสถานะต้นทางและปลายทางเท่านั้น

วิธีอ่านกราฟ
  • แกนนอนคือ Tdb แกนตั้งทางขวาคือ W
  • เส้นโค้งสีเทาคือ RH เส้นหนาคือ RH 100 % (อิ่มตัว)
  • เส้นเฉียงสีส้มคือเอนทัลปี h ตัวเลขอยู่ที่ด้านนอกเส้นอิ่มตัว
  • เส้นประสีน้ำเงินคือ Twb ซึ่งเกือบขนานกับเส้น h แต่ไม่ทับกัน
  • เส้นชันสีม่วงคือปริมาตรจำเพาะ v
  • จุดน้ำค้างอ่านได้โดยลากเส้นแนวนอนจากจุดไปทางซ้ายจนชนเส้นอิ่มตัว (วงกลมโปร่ง)
  • พื้นที่สีเขียวคือเขตเป้าหมายของห้อง
